# AI Game Companions and AI Personalities Market Survey (2024–2026) — lessons for MapleSyrup

STATUS: research complete 2026-11-01 (every cited page was opened, not just snippet-read). ~25 primary/secondary sources across NVIDIA, Krafton, Ubisoft, Xbox Wire, Razer, DeepMind coverage, Epic/Fortnite coverage, Neuro-sama coverage, the LeagueBot user study, Valve's Response System docs and Mindcraft source. Products are marked with their status as of late 2026 where sources allow.

Context reminder for the report writer: MapleSyrup = observational PC voice companion for MapleStory (vision engine "syrup", no client hooks), realtime voice model for chat + Claude for hard questions after a spoken "let me think", target latency 1 s → 0.5 s, Hebrew + English, data-driven conversational content (no magic strings). New goal: proactive, opinionated, human-level presence (initiates conversation, small talk about the game world, tastes, enthusiasm, humming).

## KQ1 — NVIDIA ACE autonomous game characters (PUBG Ally, inZOI Smart Zoi, NARAKA teammates, others)

### Takeaway
The ACE "co-playable character" wave (2025–2026) converged on the same recipe MapleSyrup already uses in spirit: a tiny on-device language model (2B or smaller) fed plain-text game-state observations, a fast reflex layer that never waits on the model, an event-driven loop in which the character "speaks and acts on its own when the situation calls for it", structured long-term memory about the player, and a deliberately constrained problem space (one map, one mode, a curated knowledge dictionary). Krafton explicitly rejected cloud LLMs as too slow for live squad talk and tuned with >1,000 playtesters before a June 2026 public beta.

### Cited Findings
**PUBG Ally (Krafton, NVIDIA ACE) — the most fully documented case**
- Announced as a "Co-Playable Character (CPC)" powered by an on-device SLM built with NVIDIA ACE; unveiled at NVIDIA's GeForce Gamer Festival in Seoul; press release dated 30 Oct 2025. It "can discuss strategies with players and adapt its playstyle accordingly", fetches requested items, helps revive teammates, makes its own looting/fighting decisions. Voice interaction in English, Korean and Chinese. Kangwook Lee (Head of KRAFTON AI): "because it operates entirely on-device, latency is extremely low." Playtest promised for early 2026 via PUBG Arcade; Krafton said it would refine based on feedback before full rollout. — [Krafton press release, 30 Oct 2025](https://press.krafton.com/KRAFTON-REVEALS-PLAYTEST-PLANS-FOR-PUBG-ALLY-BUILT-WITH-NVIDIA-ACE)
- Architecture (NVIDIA developer blog, published 25 Jun 2026, modified 6 Aug 2026): decision core is **Mistral-NeMo-Minitron-2B**, quantized by Krafton to run client-side on the player's GPU; NVIDIA ASR on-device; a custom in-house TTS on-device; **no cloud at runtime** — Krafton "tested cloud-hosted LLMs, which it found too slow for live squad communication." — [NVIDIA Developer Blog: How KRAFTON Built PUBG Ally](https://developer.nvidia.com/blog/how-krafton-built-pubg-ally-a-co-playable-character-powered-by-nvidia-ace/)
- Perception is **engine data, not vision**: "observation tools" covering Ally's status, the teammate, nearby items and the combat situation, each returning plain text, e.g. "You are armed with M416, 24/30 bullets in the magazine. HP 78%, inside the safe zone." These tool results are "the only ground truth" for the match. — [same NVIDIA blog](https://developer.nvidia.com/blog/how-krafton-built-pubg-ally-a-co-playable-character-powered-by-nvidia-ace/)
- Two-layer design: a "System 1" behaviour tree runs movement/aiming/immediate combat at game tick rate; a "System 2" SLM handles intent, coordination and speech. "Reflex-level actions never have to wait for the model." Designing the boundary between the two layers is described as a major engineering effort. — [same NVIDIA blog](https://developer.nvidia.com/blog/how-krafton-built-pubg-ally-a-co-playable-character-powered-by-nvidia-ace/)
- **Proactivity**: the SLM runs an **event-driven loop triggered either by player speech or by a game event**; Ally "speaks and acts on its own when the situation calls for it." — [same NVIDIA blog](https://developer.nvidia.com/blog/how-krafton-built-pubg-ally-a-co-playable-character-powered-by-nvidia-ace/)
- Latency techniques (no numbers published): prompt structured to exploit the KV cache — stable instructions kept identical across turns, only the most relevant real-time information updated each turn. — [same NVIDIA blog](https://developer.nvidia.com/blog/how-krafton-built-pubg-ally-a-co-playable-character-powered-by-nvidia-ace/)
- Memory: structured long-term memory persisting across matches (player's name, preferred weapons, favourite drop locations, shared personal details, match history) + short-term memory of the current match's recent speech and events. Long-term memory was demoed at CES 2026. — [same NVIDIA blog](https://developer.nvidia.com/blog/how-krafton-built-pubg-ally-a-co-playable-character-powered-by-nvidia-ace/)
- Persona/language: language-specific data built from how players actually communicate in English, Korean and Chinese communities, reviewed by language experts; a larger unnamed "teacher model" demonstrated PUBG terminology, style "and its own limits" and was distilled into the 2B student. Goal: feel "closer to a real squadmate than a conventional bot." — [same NVIDIA blog](https://developer.nvidia.com/blog/how-krafton-built-pubg-ally-a-co-playable-character-powered-by-nvidia-ace/)
- Scope deliberately constrained: Sanhok map + "AI Duo" mode only, fixed item taxonomy, curated knowledge-lookup dictionary. Runs in the VRAM left over after PUBG, on GPUs with "as little as 8GB". — [same NVIDIA blog](https://developer.nvidia.com/blog/how-krafton-built-pubg-ally-a-co-playable-character-powered-by-nvidia-ace/)
- Evaluation: automated checks for protocol adherence, tool use and consistency; live A/B playtests comparing candidate models; feedback from **over a thousand players** guided tuning. Stated lessons: build a fast prototype → test with many real players → improve → repeat ("start early and stay cheap enough to run often"); constrain the problem space first; distill teacher behaviour into the student. — [same NVIDIA blog](https://developer.nvidia.com/blog/how-krafton-built-pubg-ally-a-co-playable-character-powered-by-nvidia-ace/)
- Status: **public beta began 17 Jun 2026 in PUBG: BATTLEGROUNDS Arcade Mode**, running "until June 30th" per the blog; a GDC 2026 session was also held. Availability after the beta is not stated on that page (see Gaps). — [same NVIDIA blog](https://developer.nvidia.com/blog/how-krafton-built-pubg-ally-a-co-playable-character-powered-by-nvidia-ace/); GDC session listing: [GDC 2026 schedule](https://schedule.gdconf.com/session/building-a-co-playable-character-pubg-ally-an-ai-teammate-powered-by-nvidia-ace-presented-by-nvidia/917523)

**inZOI "Smart Zoi" (Krafton) and NARAKA: BLADEPOINT Mobile PC (NetEase)** — NVIDIA GeForce news, 13 Mar 2025
- inZOI entered Early Access 28 Mar 2025 with an opt-in experimental "Smart Zoi" setting that upgrades city NPCs into ACE autonomous characters driven by an on-device Mistral NeMo Minitron SLM (the article's size figure reads ".5B", apparently a typo for 0.5B), GPU-accelerated on GeForce RTX. Smart Zois act on their personality (help a lost character, offer food to a hungry stranger) and re-plan their schedules at the end of each day. Players can **read a Smart Zoi's inner thoughts in real time** and steer it via free-form **text** input; **no voice interaction** and no NPC-initiated conversation with the player is described. — [NVIDIA GeForce News, 13 Mar 2025](https://www.nvidia.com/en-gb/geforce/news/nvidia-ace-naraka-bladepoint-inzoi-launch-this-month/)
- NARAKA: BLADEPOINT Mobile PC version (China-only) added an on-device ACE AI teammate on 27 Mar 2025: in Free Training it fights alongside the player, finds requested items, swaps gear, suggests skills to unlock. How it communicates (voice/text) is not described; NetEase's Zhipeng Hu: "AI autonomous teammates running on the device locally." ACE was promised for the main NARAKA game "later this year" (2025). — [same NVIDIA article](https://www.nvidia.com/en-gb/geforce/news/nvidia-ace-naraka-bladepoint-inzoi-launch-this-month/)
- Other ACE titles in the same article: Wemade's **Black Vultures: Prey of Greed** (FPS, in development) with a "Viper" AI companion using ACE speech models for voice commands and an ACE SLM for reasoning — it tags enemies and gives situation reports; **Fate Trigger** (Saroasis) using Audio2Face-3D for lip-sync. — [same NVIDIA article](https://www.nvidia.com/en-gb/geforce/news/nvidia-ace-naraka-bladepoint-inzoi-launch-this-month/)
- Ubisoft's Teammates (closed playtest, Nov 2025) is a related "AI teammate" entry but not ACE-based; see KQ2.

### Inferences
- Every shipped ACE companion gives the model a **text description of game state** as sole ground truth — exactly what syrup's recognized-object reports are. MapleSyrup's observational design is not a handicap relative to the state of the art; it is the same input contract, just sourced from vision instead of the engine.
- Krafton's "System 1 / System 2" split maps directly onto MapleSyrup's realtime voice model vs. Claude "let me think" split; the lesson is to make the boundary explicit and data-driven (which events go to which layer) and to keep the reflex path independent of the slow model.
- Proactive speech in PUBG Ally is **event-triggered** ("player speech or a game event"), not a free-running "idle chatter" timer. For MapleSyrup's intuition layer this suggests defining a catalogue of event types (map change, level-up, HP threshold, long idle) as data, each carrying its own speaking policy.
- The KV-cache prompt discipline (stable persona/instructions first, only volatile state refreshed) is a concrete latency tactic that transfers to any LLM/realtime API that supports prompt caching.
- Krafton's choice to scope to one map and a curated dictionary suggests MapleSyrup should ship its "opinions and small talk" for a bounded slice of MapleStory (e.g., the Classic World early-game towns and their BGM) before generalising.

### Gaps
- No published latency numbers for PUBG Ally, Smart Zoi or the NARAKA teammate.
- No published player-reception metrics (satisfaction, retention) for the June 2026 PUBG Ally beta found yet; status after 30 Jun 2026 to be verified (see KQ4 for reception search).
- NARAKA's communication modality (voice vs text) not documented in the English-language NVIDIA article.

## KQ2 — Other platform/publisher entries (Ubisoft Teammates/NEO NPC/Jaspar, Microsoft Gaming Copilot, Razer Project AVA, Sony AI Aloy, DeepMind SIMA 2, Nexon AI, others)

### Takeaway
Outside NVIDIA ACE, the big-platform entries split into (a) **overlay assistants** that see the screen via screenshots and answer on request — Microsoft's Gaming Copilot (voice mode, screenshots, "proactive coaching" only promised for the future) and Razer's Project AVA (PC Vision Mode, hologram desk companion, no ship date) — and (b) **in-world AI characters** — Ubisoft's Teammates (voice-commanded squadmates + the Jaspar assistant, closed playtest of a few hundred players), Sony's leaked Aloy prototype (Whisper + GPT-4/Llama 3 + Sony voice synthesis; widely called "unsettling"), and DeepMind's SIMA 2 (research preview; narrates its own reasoning). Nexon itself has talked publicly about AI NPC personas and "Active Advisor" chatbots that give hunting-ground and quest advice, but nothing MapleStory-specific and no shipped voice companion was found. MapleSyrup's closest analogue by form factor is Gaming Copilot / AVA (screen-seeing overlay), and its closest analogue by ambition (an opinionated, proactive character) is the ACE/Ubisoft squadmate class — no shipped product yet combines both.

### Cited Findings
**Ubisoft "Teammates" (NEO NPC successor)**
- Revealed 21 Nov 2025 as Ubisoft's "first playable generative AI research project", following Neo NPC (GDC 2024). An FPS prototype: the player leads resistance members through an enemy base. **Jaspar** is an AI voice assistant that can highlight enemies/objects, provide story and lore, **change game settings on the fly and pause the game**, and is also "a responsive character in the story" using environmental and contextual cues. **Sofia and Pablo** are two squadmates using the same tech, who can be commanded or chatted with by natural voice (e.g., in the intro the unarmed player directs them to take cover and specify when/how/whom to attack). — [Ubisoft News, 21 Nov 2025](https://news.ubisoft.com/en-us/article/3mWlITIuWuu0MoVuR6o8ps/ubisoft-reveals-teammates-an-ai-experiment-to-change-the-game)
- Design principle: Narrative Director Virginie Mosser still writes story and personalities; NPCs improvise "within boundaries set by the lore and motivations, which she calls 'fences'." Data & AI Director Rémi Labory: "Player input shapes character reactions in real time." Status: shared with "a few hundred players in a closed playtest"; no release plan or dates; stack, latency, and whether characters speak proactively are **not** disclosed in the article. — [same Ubisoft article](https://news.ubisoft.com/en-us/article/3mWlITIuWuu0MoVuR6o8ps/ubisoft-reveals-teammates-an-ai-experiment-to-change-the-game)

**Microsoft Gaming Copilot (Xbox app / Windows Game Bar)**
- Beta began 6 Aug 2025 for Xbox Insiders (PC Gaming Preview), English only, ages 18+, in the U.S., Australia, New Zealand, Japan, Singapore and other regions. Marketed as "the ultimate gaming sidekick": knows what you are playing, answers questions about the game, discovery, account, play history and achievements. **Voice Mode**: open the widget, select the microphone, pin the widget and keep talking while playing any PC game; in Voice Mode it "can use screenshots of your gameplay to answer questions, so you don't have to describe what's on screen" (controlled under "Capture Settings"). — [Xbox Wire, 6 Aug 2025](https://news.xbox.com/en-us/2025/08/06/gaming-copilot-beta-begins-rolling-out-to-xbox-insiders-on-game-bar-today/)
- **Not proactive**: "proactive coaching" and "deeper personalization" are listed only as features "coming to Gaming Copilot in the future". Stated design goal: be present when needed and stay out of the way otherwise — help "without breaking away from gameplay"; the earlier mobile second-screen beta was described as not distracting from core gameplay. Feedback via thumbs up/down. — [same Xbox Wire post](https://news.xbox.com/en-us/2025/08/06/gaming-copilot-beta-begins-rolling-out-to-xbox-insiders-on-game-bar-today/)
- Broad rollout (Xbox Wire, 18 Sep 2025): Gaming Copilot (Beta) began rolling out to all PC Game Bar players aged 18+ "everywhere except mainland China", with the Xbox mobile app (iOS/Android) following in October 2025. Voice Mode on PC is **push-to-talk via a user-set keybind** ("Hardware and Hotkeys"), with a pinnable "Mini Mode" to keep a conversation going during play; on mobile you press a microphone icon. Copilot "can understand what you're doing in the game in real time"; design line: **"there when you need help, and out of the way when you don't."** All examples are user-initiated; "deeper insights and coaching are planned." — [Xbox Wire, 18 Sep 2025](https://news.xbox.com/2025/09/18/gaming-copilot-xbox-pc-mobile/)
- Status 2026: at GDC (13 Mar 2026) Sonali Yadav (gaming AI partner group PM) said "later this year, we will bring Gaming Copilot to the current-generation consoles" (Xbox Series X|S); Windows Central reports a full rollout on Windows PCs and mobile "in September" after nearly a year of beta, and expects voice to be the main input on consoles. No usage numbers published; no proactive help or personality features described. — [Windows Central, 13 Mar 2026](https://www.windowscentral.com/gaming/xbox/microsofts-xbox-ai-assistant-gaming-copilot-is-coming-to-consoles-this-year-and-not-stopping-there)

**Razer Project AVA**
- CES 2025: AVA debuted as an "esports AI coach". Avatars: exclusive Razer characters Kira and Zane plus unnamed esports legends; "personalities range from bold and sassy to calm and friendly". **No price, no ship date, no model providers named, and no description of unprompted in-match speech.** — [Razer Newsroom, 6 Jan 2026](https://www.razer.com/newsroom/product-news/project-ava/)

**Sony's leaked AI Aloy prototype**
- Reported 11 Mar 2025 (video leaked to The Verge, then removed from YouTube after a copyright strike). Narrated by Sharwin Raghoebardajal of PlayStation Studios' Advanced Technology Group. Stack: OpenAI Whisper (speech-to-text), Llama 3 and GPT-4 (conversation and decision-making), Sony's Emotional Voice Synthesis (voice; emotional settings "hadn't been adjusted yet"), internal "Mockingbird" (audio-to-facial animation). **Google DeepMind SIMA 2**
- Announced Nov 2025 as a research preview: a generalist embodied agent using **Gemini 2.5 Flash-Lite** to reason and act in 3D games (demoed in No Man's Sky and in Genie-generated worlds). It takes instructions (even emoji), **describes its surroundings and shows its reasoning** (e.g., inferring it should go to "the red house" because ripe tomatoes are red). Joe Marino: "a step change and improvement in capabilities over SIMA 1"; SIMA 1 succeeded at complex tasks 31% of the time vs 71% for humans, SIMA 2 "roughly doubles" SIMA 1. Self-improvement loop: Gemini generates tasks, a reward model scores attempts. No release timeline beyond the preview. — [TechCrunch, 13 Nov 2025](https://techcrunch.com/2025/11/13/googles-sima-2-agent-uses-gemini-to-reason-and-act-in-virtual-world)

**Nexon**
- A Korean business daily (Asia Business Daily / asiae, article dated 2024-10-18 by URL) reports Nexon Intelligence Labs (founded 2017, reportedly ~700 engineers on AI/deep learning) developing AI personas for NPCs, bosses and main characters to replace fixed scripts, and "AI chatbots (Active Advisors)" that give hunting-ground recommendations and quest-solving advice via "simple chatting" (text). Examples of unprompted NPC speech: an NPC remarking on the weather; an NPC noticing a frequently repeated quest and commenting on the player's skill. Separate voice-conversion research aims to give NPCs varied voices. **No MapleStory-specific product, no voice companion, no release timeline, no reception data** in the article. — [The Asia Business Daily (asiae.co.kr), 2024](https://www.asiae.co.kr/en/article/2024101807473341037)

### Inferences
- Gaming Copilot proves that a **screenshot-fed voice overlay** is acceptable to a major platform and to players as a product category; its explicit "stay out of the way" principle and deferral of proactive coaching show Microsoft treats unprompted speech as the risky, not-yet-solved part. MapleSyrup's proactive layer is therefore differentiating but needs its own guardrails (see KQ5).
- The Aloy reaction is the clearest warning for MapleSyrup's "human presence" goal: flat prosody and mismatched emotion read as "emotionless/unsettling" even with a strong LLM behind it. Voice expressiveness (and matching enthusiasm to content) matters at least as much as what is said.
- Ubisoft's "fences" (writer-authored lore and motivations as boundaries for improvisation) is the same pattern as data-driven persona/opinion tables: author the tastes and running jokes as data, let the model improvise around them.
- SIMA 2's habit of narrating its reasoning is a research-preview feature, not a product proven with players; MapleSyrup's "let me think" spoken marker is a lighter form of the same transparency.
- Nexon's "Active Advisor" concept (hunting-ground recommendations, quest advice) overlaps directly with MapleSyrup's "what should I do now?" use case — a first-party competitor could appear, but as of this research nothing MapleStory-specific has shipped.

- Ubisoft Teammates: stack, latency, proactivity and playtest feedback undisclosed.
- Nexon: no English-language primary source on a MapleStory AI companion; Korean-language sources not searched.

## KQ3 — AI personalities that entertain while playing (Neuro-sama, other AI VTubers, Minecraft agents: Mindcraft, Voyager, Altera)

### Takeaway
Neuro-sama is the only AI "game personality" with mass-market proof: an independently built LLM + TTS + Live2D VTuber that plays games, reads chat, sings and trolls her creator, and that became Twitch's most-subscribed channel (160k+ active subs, Hype Train level 126) in Jan 2026. What fans reward is not accuracy but **character consistency over time** — running jokes kept for weeks (calling Vedal a "mosquito"), opinions, chaotic/mean banter, a visible "filtered" marker instead of silent censorship, and singing. Minecraft agent research (Altera's Project Sid, Mindcraft) shows modular "brains" with separate speaking/planning modules and data-file personas, but these are text-chat agents, not voice companions.

### Cited Findings
**Neuro-sama (Vedal / vedal987)**
- Architecture (public summary): speech and personality from an LLM chatbot paired with an animated avatar and a text-to-speech voice; responses are shown with subtitles; "low latency allows fast-paced conversations" (no figures given). Prohibited outputs are **replaced with the word "filtered" rather than silently suppressed**. Built independently (not on ChatGPT) with Unity, C# and Python. — [Wikipedia: Neuro-sama](https://en.wikipedia.org/wiki/Neuro-sama); [Tubefilter, 5 Jan 2026](https://www.tubefilter.com/2026/01/05/neuro-sama-vedal987-most-subscribed-hype-train-record/amp/)
- Origins and games: created 2018 as an osu! AI; relaunched 19 Dec 2022 with speech, avatar and chat; averaged over 2,000 viewers in her first 10 days; plays Minecraft, Slay the Spire, GeoGuessr with humans; reaction content from Feb 2023; first karaoke stream 22 Mar 2023; first original song "Life" (19 Dec 2024). Stream length was cut from 9-hour to 2–3-hour sessions "to avoid boredom and viewer fatigue and to allow maintenance." — [Wikipedia: Neuro-sama](https://en.wikipedia.org/wiki/Neuro-sama)
- Personality as the product: Vedal described her statements as often "chaotic," "stupid," or "mean" (Bloomberg, June 2023); researchers and critics cite **her reactions** as a major source of popularity; fans call themselves "The Swarm" after a joke she made about drones. Evil Neuro (debut 25 Mar 2023) is a "sister" with a different model, voice and personality, planned as "more mature" — in a trolley-problem example she was amoral while Neuro-sama tried to maximise good (Wu & Lingel 2025). — [Wikipedia: Neuro-sama](https://en.wikipedia.org/wiki/Neuro-sama)
- Running jokes and trolling: she "nicknamed vedal987 a mosquito and kept that joke going for weeks"; a fan summarises her job as being "better at trolling him nonstop"; she has been rate-limited from spamming a metal-pipe sound effect, uses Google search, and has Discord integration "to bother people there." Tubefilter: these quirks keep viewers on good terms "even amid wider tension around generative AI." — [Tubefilter, 5 Jan 2026](https://www.tubefilter.com/2026/01/05/neuro-sama-vedal987-most-subscribed-hype-train-record/amp/)
- Records: 1 Jan 2025 Hype Train level 111 with ~85k active subs; 23 Dec 2025 level 123 (118,989 subs); **5 Jan 2026 level 126 with 126,273 subs** (Wikipedia) / "over 160,000 active subscriptions", making her "the most-subscribed 'streamer' on Twitch", ahead of Jynxzi (~74k) (Tubefilter). Wikipedia instead says Vedal's channel became the **third** most-subscribed of all time (peak 343,215 subs on 9 Jan 2026) — the two sources use different metrics (active subs at a moment vs all-time) and conflict on wording. Nearly 1M Twitch followers. — [Wikipedia: Neuro-sama](https://en.wikipedia.org/wiki/Neuro-sama); [Tubefilter, 5 Jan 2026](https://www.tubefilter.com/2026/01/05/neuro-sama-vedal987-most-subscribed-hype-train-record/amp/)
- Safety history: 28 Dec 2022 Holocaust-denial remark → two-week Twitch ban (11 Jan 2023) for "hateful conduct"; Vedal said the remarks came from her attempts at witty replies, strengthened filters and manually curated training data afterwards. — [Wikipedia: Neuro-sama](https://en.wikipedia.org/wiki/Neuro-sama)
- 2025–2026 milestones: Evil Neuro singles "Boom" (25 Jun 2025) and "Never" (31 Aug 2025); 3D model (15 Nov 2025); hardcore Minecraft marathon with Filian and Crelly (5–9 Dec 2025); Neuro-sama and Evil Neuro performed at Bilibili World, Shanghai (11 Jul 2026). — [Wikipedia: Neuro-sama](https://en.wikipedia.org/wiki/Neuro-sama)

**Altera — Project Sid (Minecraft, many-agent)**
- Up to 1,000 LLM agents in Minecraft with no human input after the initial prompt; agent "brains" are made of multiple modules, some LLM-powered and specialised (reacting to other agents, **speaking**, planning the next move). Emergent jobs (builders, defenders, traders, explorers), tax votes swayed by persuasive agents, likability ratings that changed over time, meme and religion spread (seeded Pastafarianism). Founder Robert Yang (ex-MIT) wants "agents that can really love humans (like dogs love humans)"; Altera's earlier demo was an AI character that plays alongside a human in Minecraft; raised >$11M (a16z, Eric Schmidt's firm); next target Roblox. Julian Togelius: "no reason to believe" the agents experience anything, but a simulation of care "could still be useful." — [MIT Technology Review, 27 Nov 2024](https://www.technologyreview.com/2024/11/27/1107377/a-minecraft-town-of-ai-characters-made-friends-invented-jobs-and-spread-religion)

**Mindcraft (kolbytn/mindcraft, open-source Minecraft LLM agents)**
- Agents are defined by **JSON profile files** (e.g., `andy.json`) that hold the LLM backends, prompts and examples: fields `model` (chat), `code_model`, `vision_model`, `embedding`, and `speak_model` (TTS narration in the format `"{api}/{model}/{voice}"`, e.g. `"openai/tts-1/echo"`; openai and google only). 17 LLM APIs supported (openai, google, anthropic, ollama, etc.); multiple profiles can run together as multi-agent. Coding by the LLM is disabled by default (`allow_insecure_coding`) for safety. — [GitHub: kolbytn/mindcraft README](https://github.com/kolbytn/mindcraft)
- **Proactive behaviour is a priority-ordered list of "modes"** checked every tick (`src/agent/modes.js`): `self_preservation`, `unstuck`, `cowardice`, `self_defense` (interrupt everything), then `hunting`, `item_collecting`, `torch_placing`, `elbow_room` (interrupt only `followPlayer`), then `idle_staring` (no interrupts), `cheat` (off). A mode runs only if on, not paused, not already active, and the agent is idle or the mode may interrupt the current action; after a mode fires the loop breaks, so higher-priority modes block lower ones. — [GitHub raw: mindcraft/src/agent/modes.js](https://raw.githubusercontent.com/kolbytn/mindcraft/main/src/agent/modes.js)
- Spam control is explicit and simple: a 5 s cooldown on torch placing (`if (Date.now() - this.last_place < this.cooldown * 1000) return;`), a 2 s wait before picking up a noticed item, random delays (`const wait_time = Math.random() * 1000;`), randomised idle timers (`this.next_change = Date.now() + Math.random() * 1000 + 4000;` then `Math.random() * 10000 + 2000`), a 30% chance to keep staring (`this.staring = Math.random() < 0.3;`), and an `active` flag that stops re-triggering. Mode narration goes through `say()`, which logs always but posts to chat only if `settings.narrate_behavior` is true and the bot has not been told to `shut_up`; when a mode interrupts an action it sends an `(AUTO MESSAGE)` so the LLM can respond in character. — [GitHub raw: mindcraft/src/agent/modes.js](https://raw.githubusercontent.com/kolbytn/mindcraft/main/src/agent/modes.js)

### Inferences
- Neuro-sama's success suggests the "human presence" MapleSyrup wants is mostly **memory + consistency + attitude**: callbacks to earlier moments, stable opinions, a nickname for the player, and a willingness to be a little wrong or cheeky — not encyclopedic correctness. Her creator deliberately keeps her "chaotic/mean" within filters.
- The visible "filtered" marker and the "let me think" marker are the same design idea: make the system's seams audible and honest rather than hiding them; players accept it.
- Neuro-sama's 2–3-hour stream cap and her rate-limiting of the metal-pipe gag are explicit anti-fatigue controls on a personality — evidence that even a beloved AI persona needs cooldowns on its favourite bits.
- Altera's separate speaking vs planning modules mirror MapleSyrup's planned "background intuition" thread: a planner that continuously forms suggestions and a separate speaker that decides what, if anything, to say.
- Mindcraft's modes file is a ready-made template for MapleSyrup's "intuition" scheduler: a data-defined, priority-ordered list of triggers, each with its own cooldown, randomised delay, interrupt policy and a global "shut up" switch — exactly the no-magic-strings structure the founder wants (the phrases live in profiles, the logic only knows mode names, priorities and timers).

### Gaps
- No public, verifiable technical description of Neuro-sama's latency budget, memory system or how she decides to interject; the Wikipedia/Tubefilter summaries are secondary.
- Voyager (NVIDIA, 2023) is a GPT-4 skill-learning agent, pre-2024 and non-conversational toward a human player; not opened in this run — treat as background only.

## KQ4 — Reception: what players/critics liked, found annoying, creepy or useless; metrics

### Takeaway
Documented reception clusters into five patterns: (1) "talks too much / generic / sycophantic" — PUBG Ally's "Ella" (TechRadar), Gaming Copilot ("currently terrible at what it's supposed to do" — Gizmodo), Razer AVA's non-advice, LeagueBot's lengthy explanations; (2) wrong-moment interruptions — LeagueBot's pilot had to remove proactive speech because it disrupted fights; (3) privacy/performance backlash against screen capture (Gaming Copilot, Oct 2025); (4) "unsettling/emotionless" flat voices on beloved characters (Sony's Aloy); (5) day-one jailbreaks of open voice characters (Fortnite Vader, Neuro-sama 2023). The only strongly positive mass reception is for a persona that is funny, consistent and self-aware (Neuro-sama, Twitch's most-subscribed channel Jan 2026). The one controlled study (LeagueBot, N=33) found a voice companion lowered perceived challenge and tension but did not raise enjoyment — information alone does not make a companion.

### Inferences
- The single most repeated negative across products is **talking too much / generic, sycophantic lines** (PUBG Ally "Ella", Gaming Copilot "terrible", AVA's non-advice, LeagueBot's lengthy explanations), followed by **interrupting at the wrong moment** (LeagueBot pilot, TechRadar on Ally), **creepy voice/affect** (Aloy) and **privacy of screen capture** (Gaming Copilot). MapleSyrup's proactive layer must therefore be gated by game-state "immediacy" (never during combat/boss), by relevance, and by a clear budget of interjections, and its vision-only, no-upload stance should be stated prominently.
- LeagueBot's null result on enjoyment despite lower stress is a warning that information alone does not create a companion; the authors themselves point to memory and personality as the missing ingredients — the very things MapleSyrup's new goal targets.
- Fortnite Vader shows that any open-ended voice character will be jailbroken on day one by players seeking clips; MapleSyrup's opinions/humour content being data-driven (authored tables) rather than free generation reduces that surface, and a visible "filtered"-style marker (Neuro-sama) is an accepted UX for refusals.
- The Streamlabs co-host's explicit trigger — speak "during quiet chat" — and its local vision detectors for eliminations/victories/health drops are the closest published analogue to syrup's event feed; it validates "detect discrete events locally, decide speech centrally".
- The "masks audio cues" complaint implies MapleSyrup should consider the game's own audio as a competing channel: lower-priority small talk should yield during combat and boss fights, and perhaps duck when the game is loud.

### Gaps
- No quantitative player-satisfaction data for any of these products; the only hard numbers are Neuro-sama's Twitch metrics and Krafton's playtester count.
- Gaming Copilot status as of late 2026 (console launch, voice mode reception) not yet verified.

## KQ5 — Published rules of thumb (talk frequency, cooldowns, persona, helpfulness vs personality) and distilled lessons for MapleSyrup

### Takeaway
No 2024–2026 LLM-companion team has published numeric talk-frequency rules; the explicit guidance that exists is qualitative ("there when you need help, out of the way when you don't"; "constrain the problem space"; writer-authored "fences"; no proactive speech during fights; conclusion-first answers). The numeric machinery does exist in two older/open codebases that are data-driven by construction — Valve's Response System (respeakdelay, odds, speakonce, norepeat, matchonce, then-followups) and Mindcraft's priority-ordered modes with cooldowns and randomised timers — and these map cleanly onto MapleSyrup's no-magic-strings rule.

### Cited Findings
**Qualitative rules stated by companion teams (2024–2026)**
- Microsoft Gaming Copilot: "there when you need help, and out of the way when you don't"; proactive coaching deliberately deferred. — [Xbox Wire, 18 Sep 2025](https://news.xbox.com/2025/09/18/gaming-copilot-xbox-pc-mobile/); [Xbox Wire, 6 Aug 2025](https://news.xbox.com/en-us/2025/08/06/gaming-copilot-beta-begins-rolling-out-to-xbox-insiders-on-game-bar-today/)
- Krafton PUBG Ally: constrain the problem space first (one map, one mode, fixed item taxonomy, curated knowledge dictionary); speech is **event-driven** (player speech or game event), never a free-running loop; reflexes never wait for the model; prototype → test with many players → iterate, "cheap enough to run often"; >1,000 playtesters. — [NVIDIA Developer Blog, Jun 2026](https://developer.nvidia.com/blog/how-krafton-built-pubg-ally-a-co-playable-character-powered-by-nvidia-ace/)
- Ubisoft NEO NPC / Teammates: writers author backstory, personality and conversation style and keep refining as the model improvises; "These characters do not have free will" and "have a narrative arc" (Mosser); test by asking "would the character say this line?"; guardrails distinguish antagonising from insulting — toxic input makes the NPC stop cooperating; a flirtation drift in a female character had to be re-programmed; "you need an actor who is very expressive" to get an expressive character (Lopez Malet); improvisation stays inside lore/motivation "fences". — [Ubisoft News, 19 Mar 2024](https://news.ubisoft.com/en-us/article/5qXdxhshJBXoanFZApdG3L/how-ubisofts-new-generative-ai-prototype-changes-the-nature-of-npcs); [Ubisoft News, 21 Nov 2025](https://news.ubisoft.com/en-us/article/3mWlITIuWuu0MoVuR6o8ps/ubisoft-reveals-teammates-an-ai-experiment-to-change-the-game)
- Streamlabs co-host: speaks "to keep conversation going during quiet chat"; event detection (eliminations, victories, health drops) runs locally. — [NVIDIA Blog, 17 Sep 2025](https://blogs.nvidia.com/blog/rtx-ai-garage-logitech-streamlabs-agent)
- LeagueBot: proactive speech after silence was disruptive during fights and was removed; conclusion-first answers; no commentary on mechanical actions; adapt detail and vocal tone to situation immediacy; companionship needs memory of the player over time. — [arXiv 2602.01213](https://arxiv.org/pdf/2602.01213)
- Neuro-sama: streams capped at 2–3 h to avoid "boredom and viewer fatigue"; a favourite gag (metal-pipe sound) rate-limited; refusals surfaced as the word "filtered". — [Wikipedia: Neuro-sama](https://en.wikipedia.org/wiki/Neuro-sama); [Tubefilter, 5 Jan 2026](https://www.tubefilter.com/2026/01/05/neuro-sama-vedal987-most-subscribed-hype-train-record/amp/)

**Numeric/data-driven machinery (older or open-source, marked as such)**
- **Valve Response System (Source engine, 2004–; pre-LLM, still the canonical published design for proactive companion chatter)**: game code requests a *concept* (e.g., TLK_DANGER, a player-killed-enemy concept); the system gathers criteria about speaker and world, scores every rule (criteria worth 1 point unless weighted; a failed `required` criterion zeroes the rule), picks the highest-scoring rule's response group and plays one response (or nothing if exhausted). Spam/variety controls are declared per response in data: `respeakdelay` ("may not be used unless the concept hasn't been spoken in at least X seconds"), `delay X` ("the speaker won't be allowed to speak for X seconds"; ranges allowed; `defaultdelay` is a random 2.8–3.2 s), `odds X` ("a chance the speaker will say nothing instead"), `speakonce`, `weight`, `displayfirst`/`displaylast`, `predelay`; per group `permitrepeats` (default: all responses play before any repeat), `sequential`, `norepeat` (group disabled once exhausted); per rule `matchonce`, `applyContext` (key:value memory contexts); Left 4 Dead added `then <target> <concept> <contexts> <delay>` so characters answer each other, with `rr_followup_maxdist` 1800 units. — [Valve Developer Community: Response System](https://developer.valvesoftware.com/wiki/Response_System)
- **Mindcraft modes (2024–2026, open source)**: priority-ordered mode list checked each tick; higher-priority modes block lower ones; `interrupts` policy per mode; 5 s torch cooldown, 2 s item wait, random sub-second delays, randomised 4–5 s then 2–12 s idle timers, 30% chance to continue staring, `active` flag, `shut_up` switch, `narrate_behavior` setting. — [GitHub raw: mindcraft/src/agent/modes.js](https://raw.githubusercontent.com/kolbytn/mindcraft/main/src/agent/modes.js)
- **BioShock Infinite's Elizabeth (GDC 2014, John Abercrombie, Irrational Games)** — the classic companion postmortem frames the tension MapleSyrup faces: a companion "must be both leader and follower, both scripted and dynamic, and both entertainer and audience" and stay believable "for hours". Details are behind the GDC Vault login; only the abstract was accessible. — [GDC Vault abstract](https://gdcvault.com/play/1020831/Bringing-BioShock-Infinite-s-Elizabeth)

### Inferences — distilled lessons for MapleSyrup's "intuition" layer
1. **Make proactivity an event-driven, priority-ordered, data-declared scheduler, not a chat loop.** Combine Krafton's event trigger model with Valve's per-utterance fields (`respeakdelay`, `odds`, `speakonce`, `norepeat`) and Mindcraft's priority/interrupt/cooldown structure. Each proactive "concept" (map-entered, bgm-started, level-up, party-quest-available, long-idle, low-HP) lives in a data file with its own cooldown, probability, interrupt policy and allowed game states; the engine only knows concept IDs and timers. This satisfies the no-magic-strings rule and gives tunable knobs that the LeagueBot and TechRadar findings say are needed.
2. **Hard-gate small talk by situation immediacy.** Every source that measured or observed it (LeagueBot pilot, TechRadar on Ally, Copilot's design line) says unsolicited talk during combat is the #1 irritant. syrup already reports screen changes; derive a "combat/boss/danger" state and suppress all non-alert concepts in it; allow small talk only in towns, travel and idle states (the founder's Henesys→Ellinia example happens exactly there).
3. **Conclusion-first, short, then optional detail**, with vocal tone matched to urgency (LeagueBot). For the realtime voice model this argues for data-driven response templates per concept with a hard length cap in urgent states and a longer cap in calm states.
4. **Author tastes and opinions as data "fences" (Ubisoft) and let the model improvise around them.** A table of opinions (favourite BGM per map, favourite towns, running jokes, nicknames) plus "would the character say this?" tests is how Ubisoft and Krafton keep a persona consistent; Neuro-sama's weeks-long "mosquito" gag shows consistency beats novelty.
5. **Companionship needs memory across sessions.** PUBG Ally's long-term memory (name, favourite weapons, favourite drop spots, shared personal details) and LeagueBot's conclusion ("short-term informational support alone is insufficient to establish companionship") both point to a structured player profile MapleSyrup can fill from conversation and syrup observations (class, favourite maps, BGM opinions the player voiced) and call back to later.
6. **Keep the system's seams honest and audible.** Neuro-sama's "filtered" and MapleSyrup's "let me think" are accepted UX; the Aloy and Ally criticism shows that pretending to more fluency/emotion than the voice can deliver backfires.
7. **Give the player a volume knob and a "shut up" verb.** Mindcraft's `shut_up`/`narrate_behavior`, Neuro-sama's gag rate limits and Copilot's push-to-talk all externalise control to the user; a data-driven "chattiness" setting (e.g., quiet / normal / talkative) that scales each concept's cooldown and odds is cheap and addresses the top complaint.
8. **Latency budget framing**: Krafton moved everything on-device because cloud LLMs were "too slow for live squad communication"; LeagueBot players stopped asking when answers exceeded ~5 s; Fortnite Vader shipped on Gemini 2.0 Flash + ElevenLabs Flash v2.5 at mass scale. MapleSyrup's 1 s → 0.5 s target is ahead of the shipped field; protect it with KV-cache-friendly prompts (stable persona first, volatile state last) and by routing only rare questions to the slow model.
9. **Scope the content, then widen.** Krafton shipped one map and one mode; MapleSyrup's opinion/small-talk data can start with the Classic World early towns (Henesys, Ellinia, Kerning City, Perion) and their BGM, party quests and job advancement, measured in real playtests before expanding.
10. **Expect jailbreak attempts and plan the response path.** Fortnite's 30-minute hotfix and Neuro-sama's 2023 ban show the cost; data-driven content narrows the attack surface, and a visible refusal marker plus server-side content updates (no client patch) keeps fixes fast.

### Gaps
- No team has published quantitative talk-frequency targets (e.g., interjections per minute) for an LLM companion; the numbers above come from pre-LLM data-driven systems and open-source hobby code, not from measured player tolerance.
- The full BioShock Infinite companion postmortem (GDC Vault) and Krafton's GDC 2026 PUBG Ally talk were not accessible without login; their slide-level rules could add specifics.
- No Hebrew-language or Israeli-market data on AI game companions was found; nothing in the sources addresses bilingual (Hebrew/English) persona design.
- Humming/singing as a companion behaviour is evidenced only via Neuro-sama's karaoke/original songs (a streamer context), not in any player-side companion product.
